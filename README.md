# Flag-alJuliabra
Implementation of a flag algebra solver (modeled after Emil Vaughan's Flagmatic 1.5.1) in Julia, using JuMP for SDP solving


Navigate to examples/flag_algebra_intro for a few examples of using the tool. Flagmatic is a perfectly functional tool, and this should not be viewed as a replacement for those already using it. However, this project is written only in Julia, and is designed with REPL and Jupyter Notebook usage in mind. 

If you aren't already sending your problems off to a supercomputering cluster, I invite you to explore this repository.
